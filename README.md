# Plurimo

Plurimo is a teaching-optimization software platform, currently in design,
for private tutors and independent educators. Its site-health monitoring and
its anti-capture/anti-trolling detection are designed around Recursive
Information–Container Dynamics (RICD), the framework behind
[Tell](https://github.com/carmen-speer/Recursive-Information-Container-Dynamics).
Because those systems would rely on RICD, RICD needs to be tested against
real, adversarial data in further domains before it is trusted to run them,
and that testing comes first.
